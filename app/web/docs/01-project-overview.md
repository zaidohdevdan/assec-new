# 🏛️ ASSEC Design System & UI Skill

## 🎯 Objetivo
Portal institucional da Associação dos Servidores da Segurança do Ceará (ASSEC). Transmite credibilidade, transparência, força institucional e representatividade.

## 📦 Stack Tecnológica
- **Framework:** Next.js 15 (App Router)
- **Linguagem:** TypeScript 5.6+
- **UI:** React 19 + Tailwind CSS 3.4 + shadcn/ui
- **Formulários:** React Hook Form + Zod
- **Ícones:** Lucide React
- **Motion:** Framer Motion (controlado)
- **Deploy:** Vercel (SSR/SSG automático)

## 📜 Regra de Ouro
> Toda decisão visual/deve responder: «Isso aumenta a confiança do associado na instituição?»  
> Se a resposta for **não**, remover ou simplificar.

## 🤖 Diretrizes de Geração
1. Gere código TypeScript estrito (`strict: true`).
2. Use componentes funcionais com props tipadas.
3. Mantenha a hierarquia de títulos e cores inalterada.
4. Priorize acessibilidade nativa (ARIA, foco, teclado).
5. Evite dependências desnecessárias. Prefira APIs nativas do Next.js.
